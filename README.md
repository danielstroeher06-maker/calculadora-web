🧮 Calculadora Web

Uma calculadora web simples e funcional, desenvolvida com HTML, CSS e JavaScript.

🚀 Sobre o projeto

Este projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento web, principalmente JavaScript, manipulação do DOM, eventos e lógica de programação.

A calculadora permite realizar diferentes operações matemáticas diretamente pelo navegador, contando também com algumas funcionalidades científicas.

✨ Funcionalidades

➕ Adição

➖ Subtração

✖️ Multiplicação

➗ Divisão

🔢 Operações com números decimais

📊 Porcentagem

🔢 Potência

√ Raiz quadrada

📐 Funções científicas

🧹 Limpeza dos valores

🖥️ Interface simples e responsiva

⚠️ Tratamento de erros

🛠️ Tecnologias utilizadas

HTML5 — estrutura da página

CSS3 — estilização e layout

JavaScript — lógica e funcionamento da calculadora

▶️ Como executar

Faça o download ou clone este repositório.

Abra a pasta do projeto.

Abra o arquivo index.html em um navegador.

A calculadora estará pronta para ser utilizada.

Este projeto faz parte dos meus estudos de programação e desenvolvimento web, servindo como prática para melhorar minha lógica de programação e meus conhecimentos em JavaScript, HTML e CSS.
